# Power Park Cafe

Marketing site for **Power Park Cafe** — 186–190 Discovery Rd, Dandenong South VIC 3175.

## Stack

- Next.js + React
- Menu prices sourced from the cafe’s [Uber Eats listing](https://www.ubereats.com/au/store/power-park-cafe/wt2RCGNBUWCnu-J9cm-DxQ)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Config

Edit `lib/siteConfig.js` for phone, hours, map links, and delivery URLs.  
Edit `lib/menuData.js` / `lib/reviewsData.js` for menu and reviews.
